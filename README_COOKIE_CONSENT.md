# Cookie and privacy choices

The site stores a first-party privacy choice for up to 180 days. Essential storage remembers that choice and supports core site functions. The site does not collect visit or interaction analytics.

UTM campaign values and WhatsApp-click state may be retained for the current browser session so they can accompany a customer enquiry. Lead submissions require customer consent and are sent to the existing Google Apps Script Leads integration through `/api/enquiry`.
